Privacy Analysis and Leakage Evaluation

Rigorous empirical measurement of nearest-neighbor preservation and feature inversion error.

Implemented Protection Mechanism Architecture

1. Orthogonal Dimension Reduction

Penultimate 1280-D features projected into 512-D space via orthonormal matrix P (QR decomposition).

Compression: 1280-D → 512-D (60% dim reduction)
2. Calibrated Perturbation

Differential Gaussian noise N(0, σ²I) added on unit sphere, suppressing coordinate exactness while preserving cosine angles.

Default: σ = 0.05 (calibrated SNR)
3. AES-256-GCM Vault Isolation

Raw catalog images stored exclusively as encrypted ciphertext files. Vector DB contains strictly float32 coordinate values.

ℹ Scientific Disclosure & Threat Model Boundary

The reconstruction resistance metrics above measure empirical error under linear pseudoinverse attacks (x̂ = z · Pᵀ). Full reconstruction impossibility is not claimed; non-linear neural inversion decoders could theoretically reconstruct coarse visual outlines if the projection matrix P and training distribution are known to an adversary.

Safe Staged Rebuilding Workflow

Index rebuilding never overwrites active FAISS structures directly. The engine builds faiss_index_staging.bin in isolation, validates dimension compatibility and vector count, backs up the active index to faiss_index_backup.bin, and executes an atomic file swap. Zero search queries fail during maintenance.
