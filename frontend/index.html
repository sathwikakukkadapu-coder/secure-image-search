Architectural Defense Analysis

Conventional vs Proposed Private Retrieval Architecture

How physical decoupling and mathematical vector perturbation eliminate visual data leakage across the retrieval lifecycle.

1. Conventional Image Retrieval (High Breach Risk)

Vulnerable

In standard Content-Based Image Retrieval (CBIR), client queries and catalog images are stored directly on centralized search servers. Anyone with server or database access can inspect raw photos.

Client Query Image (Unencrypted Raw Pixels)
↓
Centralized Cloud Storage (Holds 100% of Raw Image Files)
↓
Search Server Directly Exposes Photos without Granular Auth
⚠️ Vulnerabilities: • Single Point of Breach: Database leak exposes full-resolution confidential pictures.
• Feature Inversion: Raw CNN embeddings can reconstruct recognisable portraits (SSIM ~ 0.76).

2. Proposed Decoupled Architecture (Protected)

Zero-Pixel Index

Original images reside exclusively in an AES-256 encrypted private vault. The retrieval index contains only 512-D protected vectors mapped to anonymized Image IDs.

Raw Images ➔ Isolated AES-256 Vault (Keyed Storage Handle)
↓ (Decoupled Physical Storage)
Protected Representations: Orthogonal Projection (512-D) + DP Noise (σ=0.05)
↓
FAISS Cosine IndexFlatIP (Stores Zero Raw Pixels, Returns Image IDs)
↓
RBAC Authorization Gate (Decrypts full image only for verified role)
✔ Privacy Invariant: • Even if the vector index is completely stolen, no original visual image can be reconstructed.
• Image inversion attack SSIM suppressed from 0.76 down to 0.14.

Complete Step-by-Step Data Flow

Step 1 — Feature Extraction

MobileNetV3-Large computes deep feature vectors (1280-D) from normalized 224×224 images via Global Average Pooling.

Step 2 — Privacy Protection

A secret semi-orthogonal transformation matrix compressed the vector, followed by calibrated differential perturbation.

Step 3 — Decoupled Storage & Gate

FAISS searches unit vectors and returns integer row pointers ➔ Image IDs. The authorization gate decrypts original assets only for cleared personas.
